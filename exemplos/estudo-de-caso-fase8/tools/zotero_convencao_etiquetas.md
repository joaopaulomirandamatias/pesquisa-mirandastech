# Convenção de etiquetas (slide 21)

| Prefixo | Valores | Uso |
|---|---|---|
| `status:` | ler · lido · citar · excluido | estado de leitura (as quatro coloridas, teclas 1–4) |
| `triagem:` | incluido · excluido:escopo · excluido:idioma · excluido:tipo | decisão e motivo, por revisor se houver grupo (`R1:`, `R2:`) |
| `metodo:` | estudo-de-caso · survey · experimento · revisao-sistematica | método do trabalho lido |
| `tema:` | livre, minúsculas, sem acento, hífen entre palavras | eixo temático da síntese |

Cores das anotações no leitor (slide 27): amarelo = achado; verde = método; vermelho = crítica; azul = citar literalmente.

# Projetos de exemplo

Dois projetos **fictícios** para o aluno ver como fica um `PROGRESSO.md` preenchido com evidência, decisões datadas e uso de IA registrado:

| Pasta | Cenário | Onde parou |
|---|---|---|
| `revisao-fase6/` | revisão sistemática (PRISMA 2020) | fase 6, leitura e síntese: matriz em preenchimento |
| `estudo-de-caso-fase8/` | estudo de caso único com entrevistas (CEP) | fase 8, escrita ABNT |

Para experimentar: copie a pasta, abra o Claude Code dentro dela e diga «Pesquisador, onde paramos?» — ou rode `python3 ../../scripts/relatorio_orientador.py`. Regenerar: `python3 exemplos/gerar_exemplos.py`.

# Registro de decisões

Cada decisão humana vigente recebe um número, uma data e o responsável. Nunca se apaga uma decisão: uma nova a substitui e aponta para a anterior.

> As entradas abaixo são esqueletos para as duas primeiras decisões de todo projeto; enquanto tiverem «…» no lugar dos campos, não são decisões tomadas.
